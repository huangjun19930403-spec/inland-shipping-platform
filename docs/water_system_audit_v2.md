## 重点处理

- 标准名展示、原始名追溯：`water_system_name / standard_name / display_name` 使用业务标准名，`source_names / source_remarks / source_object_ids` 保留来源追溯。
- 新增可用边界：`富春江`、`白洋淀`。
- 富春江独立于钱塘江统计，`parent_water_system_code=WS-QIANTANG-RIVER`，未并入 `富春江水库`。
- `通扬线` 使用 `新通扬运河` 原始边界，`锡澄运河` 使用 `锡澄河` 原始边界，`盐邵线` 使用 `盐邵河` 原始边界，并在业务备注中说明近似承载关系。
- `REVIEW` 和 `MISSING` 均不参与 AIS 点落区。
- 当前水系边界来自水系面数据，只用于 AIS 水域空间归属和态势展示，不代表官方航道等级、通航尺度、航道中心线或路径规划依据。
