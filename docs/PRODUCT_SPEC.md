# Product Spec

## Product Positioning

内河航运数据分析平台服务于货源经营、运力调度、航线区域分析、报价决策和数据质量治理。平台不再以“基础数据、船舶管理、货源采集、数据分析”等后台模块作为产品主线，而是围绕业务问题组织工作台。

核心业务对象是运输机会。运输机会由已确认货源、起终点、货品吨位、航线、可用运力、报价依据、风险和质量证据共同组成。

## Information Architecture

生产菜单由后端 `sys_menu` seed 和前端静态兜底菜单保持一致：

- 经营总览：经营驾驶舱、近期机会样本、审核和分析任务状态。
- 货源洞察中心：货源态势总览、微信语义解析、TMS 结构化入站、解析批次监控、候选证据池、机会样本库、供需适配分析、质量治理与回算。
- 运力中心：可用运力池、船舶台账、船舶画像、AIS 船位、节点/航线船位、可信与治理、船货适配分析。
- 航线与区域中心：航线列表、区域供需、流向分析、运输节点、业务区域、水系基础数据、通航约束点。
- 运价与报价中心：智能报价测算、运价预估测算、运价分析。
- 数据质量与治理：货源清洗、船舶资料问题、船舶治理任务、审核队列、分析刷新任务。
- 系统配置：主数据配置、权限与参数。

## Core Workflows

### 货源洞察

1. 业务人员从微信群、TMS 或补录动作沉淀货源样本。
2. AI 解析只负责结构化和辅助解释，不直接伪造结论。
3. 候选货源进入候选证据池，人工确认后生成机会样本。
4. 质量治理与回算发现原文级地点、缺城市、缺节点、缺标准货品等问题。
5. 机会样本库展示来源、质量、航线状态、运力状态、报价状态、证据和下一步动作。

### 运力中心

1. 船舶主档维护身份、档案、尺度载重、证照、船东、经营人、联系人。
2. AIS 和空间观察提供船位、城市、水系、节点、航线维度的可用性信号。
3. 质量、合规、名单和 OCR 差异形成可信度与治理任务。
4. 船货适配分析基于货源上下文、船舶能力和风险证据生成候选运力。

### 航线与区域

1. 行政区划、水系、运输节点和通航约束作为生产基础数据。
2. 航线由方案、路线、节点、分段和真实轨迹构成。
3. 地图不使用样例直线冒充真实航线。轨迹缺失时显示可计算、待生成、失败、不可计算四态。
4. 区域和流向分析必须携带样本量、覆盖率、置信度、血缘和动作入口。

### 运价与报价

1. 智能报价测算用于已知价格场景：已知货主报价、船主/船户报价或报价区间，判断可接、议价、拒绝或不可计算。
2. 运价预估测算用于未知市场运价场景：基于装卸地、货品、吨位、预计装货时间、历史可比样本、航线距离、通航约束、运力紧张度、数据质量和 fallback 层级给出价格区间。
3. 报价和预估结果必须落库到 `pricing_decision_record`，保留输入、成本/样本证据、航线证据、覆盖率、置信度、血缘、不可计算原因和推荐动作。
4. 外部路线服务不可用时，报价不得使用虚假轨迹替代真实依据；预估只能声明降级口径。
5. 运价预估不得以 `距离 * 固定系数` 作为最终市场价。必须先查找可比样本，按节点/区域、货品、吨位、时间新鲜度、距离、质量、航线可计算性、通航约束和运力供需做加权，再用分位数和异常值处理输出低位、推荐和高位价格。

### 数据质量闭环

1. 分析或业务页面发现数据缺口。
2. 生成清洗建议、治理任务或审核任务。
3. 人工修复后回算分析事实。
4. 指标的覆盖率、置信度和不可计算原因随数据质量改善而更新。

## Analysis Contract

分析响应必须面向业务问题，而不是只返回图表数据。分析类响应应包含：

- `context`：日期、区域、节点、货品、船型等上下文。
- `metrics`：指标值和口径。
- `insights`：结论、证据、样本量、覆盖率、置信度、血缘、不可计算原因、推荐动作。
- `lineage`：源表、源记录、数据版本和刷新时间。
- `quality`：覆盖率、质量等级、影响结论的问题。
- `actions`：下钻、治理、匹配、报价、刷新等可执行入口。

## Remaining Hardening Items

- 后端仍有部分历史大 service 超过 800 行，需要继续拆成领域服务、repository、rule/evidence builder。
- 前端仍有少数页面超过 700 行，需要继续拆成 workbench、panel、table、map、composable。
- 分析服务已具备血缘、质量和 map-state 口径，但还需要继续把全部图表接口收敛成统一 insight 响应。
- `local-demo` 可生成演示链路，生产环境不得把 `LOCAL_SAMPLE` 当作真实分析依据。
